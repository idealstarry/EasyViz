# Reference geometry and typography

Reproduce needs a geometry model as well as correct numbers. First inspect the reference's actual pixels. Measure the data region separately from its labels, shared keys and outer margins. When an article PDF is available, use its vector bounds and text metadata to establish physical relationships. A cropped screenshot's displayed pixels alone do not establish millimetres or font point sizes. Author code is not needed to observe these relationships.

For paired plots, identify what aligns across panels and what is decoded once. Vabistsevits Figure 3 uses three exposure blocks, the same eight outcomes in both lanes and a single shared color key. Repeating all outcome names in both lanes changed the reference's information structure and widened the data regions. Its source data frames measure about 34.84 × 100.21 mm, a width/height ratio of 0.348. The explicitly adopted revision uses 32 × 92 mm lanes, the same ratio, one eight-outcome key and three vertical exposure labels. All 48 estimates, 96 asymmetric confidence endpoints, log-axis semantics and supplied fill states remain intact. Tick positions and outcome order come from the reference and source contract; never infer missing values from mark placement.

Check type relative to the data region. Uniform typography is not always faithful. Shi Figure 1d has about 10.693 pt axis text and 8.911 pt ticks (ratio 1.20); the current reproduction's uniform 8 pt text removes that hierarchy even though the basic aspect ratio is close. It is retained as a measured control here. Conversely, the forest PDF contains outlined glyphs, so its exact font point sizes are unknown. The revision explicitly adopts editable 8 pt Arial and visibly stronger column/shared-variable headers; it does not claim to recover source font parameters. Never shrink agreed text to resolve clipping without explicitly adopting a revised specification first.

Compare marker diameter, stroke width and plot extent together. Massier Figure 1e's selected depot kBET circle is about 23.88 mm across with 3.575 pt geometric points and 0.847 pt data strokes. The previous reconstruction used a 50 mm circle while nearly preserving the point and type sizes: the marks and key looked disconnected from the enlarged data region. The revised 34 mm circle and explicitly adopted 5.1 pt points reproduce the observed geometric point/circle ratio (~0.0528 versus ~0.0529). Direct class labels require room beyond the original shared class key, so the standalone canvas remains an acknowledged adaptation. The true 0–0.5 radial scale and three coincident zeros are preserved; unknown central padding is not estimated from pixels.

Treat guide burden as part of layout. Preserve essential axes, units, ticks, class names, color keys and necessary column headers. Move narrative titles, abbreviation explanations, source notes and inference caveats into the separate caption. A shared key can relieve repeated text, but only when every lane keeps the same category/color meaning. Keep frames and grid/radial guides behind primary marks and their relative visual weight subordinate. Restore clear boundaries without letting them compete with the data.

Finally, verify the adopted design at real size. Compare original, prior output and revision with stated physical dimensions; a smaller thumbnail is not evidence of better proportion. Audit actual PDF vectors and editable text, not just renderer settings or a QA flag. The separate export audit verifies all forest endpoints and all radar vertices directly from the PDF. Independent visual review must still assess balance, legibility and residual differences. These are reference-informed rules, not a universal layout or color template.
