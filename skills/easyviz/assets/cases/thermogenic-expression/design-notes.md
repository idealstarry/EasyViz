# A reading task for the full expression matrix

The question is which supplied thermogenic genes show genotype-associated
expression differences, and how absolute expression and sample variability
relate to those differences. The absolute matrix and its aligned mean-difference
lane answer different parts of that question. A standalone scatter would not
preserve gene/sample lookup; a mean-only bar chart would hide the six supplied
sample abundances.

The adopted canvas is **112 × 128 mm**, with **Arial 8 pt** throughout. The
matrix is 44 × 90 mm: six 7.33 mm columns and 29 rows at 3.10 mm pitch. Gene
symbols are italic. Sample labels and the thin genotype band occupy their own
lanes. The 24 mm contrast lane shares exactly the same row positions and uses
outlined blue bars at 49% of the row pitch, with light reference lines below
the quantitative marks. The sample-level matrix remains the larger data region.

## Literature mechanism and intentional changes

The actual scWAT Figure 2b crop was inspected before implementation. Its
legible gene rows, contiguous sample groups, aligned label positions and small
guide footprint are transferable design mechanisms. Crisp white cell seams
and italic gene labels retain clear boundaries rather than fading the data.

The original figure is an analogue, not a visual target. Its row-standardized
colors, clustered order/dendrogram and stars are not reconstructed: exact
display z scores, linkage and per-gene numeric significance values are absent
from this source sheet. The new matrix instead uses an explicit absolute
log2(TPM + 1) scale with a 1 TPM pseudocount, preserving source order. The
warm sequential palette separates quantitative expression from categorical
gray/blue genotype decoding; blue bars then describe the named YT-AKO-minus-
YT-FF comparison. More genes are not made red merely because they differ.

The complete observed log-expression range is 0–11.6354. Bounds 0–12 include
all six observed zeros and the full maximum. All descriptive differences are
nonnegative (0–4.3019), so their axis is 0–5 rather than allocating half the
lane to unobserved negative differences. These bounds are based on the supplied
data and must be reconsidered for a new input, without clipping.

## Actual internal review

The first render is preserved in `attempts/attempt-01/`. The full PNG and the
96 dpi PDF preview were opened. It exposed an actual missing Arial subscript-2
glyph and an under-specified contrast unit. Pass 2 uses readable literal
`log2(TPM + 1)` and a two-line difference/unit header; its actual PNG and PDF
preview were opened. Pass 3 retains that visible geometry while completing
source-bound metadata, validation and compatibility with the frozen shared
element API. It is the selected final export, not an extra stylistic variant.

Numerical checks independently use copied workbook XML and Decimal arithmetic.
They also inspect the actual SVG rectangle fills/positions, the actual PDF
drawings and embedded fonts, and every PNG cell-center color. PDF font-wide
metric boxes contain empty ascender/descender padding and overlap slightly
(0.052 mm); actual embedded glyph outlines at their exported positions retain
at least 0.464 mm of visible separation. Both measurements are recorded.

## Consumed source bytes and custom handoff

After the visible design was adopted, a metadata follow-up captures one exact
data/specification/contract/script payload before drawing. The parser and
renderer use those returned bytes; snapshots are written from those payloads.
The original workbook, executed runtime helper snapshots, source/export
validator and caption are declared auxiliary inputs. An explicit alternate
font first saves its own adopted specification, with the original specification
retained as an auxiliary input. The public receipt verifies source continuity
before publishing hashes for every actual exported format.

The handoff and workbench helpers are also executed from their exact captured
bytes. The independent validator reads the actual renderer's literal helper
loaders and requires every real sibling, including its observation-clipping
dependency; it does not silently freeze an earlier shorter helper list. It
checks actual adopted physical dimensions, primary and auxiliary paths, and
the current executed-helper record against the handoff. `consumed-sources.json`
is generated by the fresh replay and records these limited byte identities.
The separately attributed reference crops remain design evidence rather than
declared numeric inputs. General library versions and undeclared environment
dependencies remain outside this receipt's proof.

This follow-up does not add a visual design iteration. A fresh unchanged-Arial
render must produce byte-identical PNG/PDF/SVG exports before its metadata is
adopted. Old metadata and independent packets are preserved separately; their
attestations are not silently rebound to changed code. Three disposable tests
mutate data, specification or contract after numerical validation and before
receipt publication. Each refuses a receipt, records failed QA and preserves
the original consumed snapshot. This demonstrates the covered race rejection;
it does not certify arbitrary plotting code or undisclosed dependencies.

## Remaining tradeoffs

Absolute abundance necessarily makes some within-row changes less prominent
than row-standardization; the separate difference lane restores lookup without
claiming standardized scores. Warm expression and blue difference are separate
scales, not opposing biological categories. Three mice per group do not support
a claim of stable population-wide effects from this descriptive view. The zero
dot is a visible origin indicator, not an imputed abundance. This case supports
one source-backed custom organization and actual-image review; it does not
establish matched aesthetic superiority to the paper, a CNS-quality guarantee,
or model-wide effectiveness.
