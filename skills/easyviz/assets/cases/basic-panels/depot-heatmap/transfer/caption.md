Source object counts for all 16 myeloid subtypes across three adipose depots in the complete Figure_2f table from Massier et al., Nature Communications (2023), DOI 10.1038/s41467-023-36983-2 (source release https://data.mendeley.com/datasets/y3pxvr4xbf/2; CC BY 4.0). All 48 author-supplied `n` values are shown on one globally linear 0–2700 count scale. Counts sum to 11,470 subcutaneous, 8,563 omental and 2,506 perivascular source objects; the color values are counts, rather than within-depot percentages. Subtype descriptors follow published Figure 2d annotations, and row/column order is retained. These pooled objects are not independent participant replicates. No expression measurement, inferential test, additional normalization, imputation or filtering is introduced; row, column and value fields are explicitly remapped for this transfer.
