# Changelog

## 0.4.0 — 2026-10-02

- Create-track directory exploration for CSV, TSV and XLSX, with source inventories, descriptive profiles and concrete figure recommendations. Inventory-only mode also serves an already selected reproduce task.
- Separate planned statistical analysis with explicit experimental units, pairing, exclusions, effects, supported intervals and declared Holm or Benjamini–Hochberg comparison families.
- Reference-plus-user-data reproduction with staged evidence and a layer-to-code plan for new implementations. Literature Source Data and author plotting code are not prerequisites.
- Shared localhost figure workbench for selectable SVG layers, physical canvas regions and version-bound requests. The Agent applies requests to code/specification and rerenders the requested formats.
- A fifth focused recipe for supplied time/dose summaries, mean ± SD or explicit asymmetric bounds, linear/log scales and optional adopted dual y axes; the core remains five chart families.
- Shi et al. Nature Communications 2021 Figure 1d case: all 120 supplied summaries and 360 numeric source strings, fresh reference reading, source/artist checks and independent visual review with recorded adaptations. Changed-data reproduce and separate synthetic create fixtures retain distinct scopes.

See the [0.4.0 QA record](evals/release-qa/v0.4.0/README.md) for checks actually run, archive identity and publication status, and the [case catalog](examples/README.md) for the supported inputs.

## 0.3.0 — 2026-10-02

- Reusable supplied-interval, paired-observation, replicate-component and ECDF tools with explicit column mappings, raw-observation layers and scientific input contracts.
- Four additional Nature-family Source Data papers covering area scatter, asymmetric intervals, complete repeated measurements and replicate components/ratios. Alternate views retain separate captions and disclosed adaptations.
- Measured first-panel layout, multiple-guide placement and cell-annotation checks preserve adopted dimensions and font sizes.
- Geometric circle-area mappings, exact unsimplified ECDF vector jumps and original numeric-text trace alongside parsed plotting values.
- Machine-readable focused-recipe discovery and actionable routing hints for Agents; absolute-path examples support multi-step use from changing working directories.
- Curated case synchronization removes stale generated files while preserving source and hand-authored assets.
- Stable portable bundle with extracted-runtime, source/geometry, actual-image and same-environment pixel-replay validation. Agent trials remain bounded usability evidence.

Install or update by giving your Agent the repository link and asking it to follow
[INSTALL.md](INSTALL.md). See [0.3.0 release checks](evals/release-qa/v0.3.0/README.md)
and the [case catalog](examples/README.md) for the tested scope.

## 0.2.0 — 2026-09-30

- Agent-led install/update from the GitHub link and INSTALL.md, with automatic packaging, catalog preservation, backups, enabled-state checks and full cache-content verification.
- Shared figure profiles for category colors, typography, independent panel dimensions, fixed continuous color scales and proportional dot-area scales.
- Strict configuration keys/types with useful spelling suggestions and explicit shared-setting conflicts.
- Distinct dot-matrix states for measured zero, unmeasured, absent and optional tiny positive values; quantitative areas and source rows are retained.
- Deterministic ZIP timestamps/permissions, content identity, extracted runtime CI checks, and version-specific local QA records.
- A paired Agent comparison with and without EasyViz on official NOAA and USGS data, with frozen inputs, initial outputs, numerical checks and anonymous review.
- Website now points to the GitHub repository.

See [0.2.0 QA](evals/release-qa/v0.2.0/README.md) and the [value pilot](evals/skill-value/README.md). Source updates and a downloadable GitHub Release are tracked separately.
