# Example request

Use Figure 1 of Gontijo et al. (2022) as the visual standard for the supplied inhibition matrix. Retain sender rows, receiver columns, the inferno color scale, top and left genome-status strips, and strain labels. Export one PDF and a PNG preview with 8 pt Arial text at 132 × 120 mm.

For this demonstration, use 12 evenly spaced ranks along each degree-ordered axis so the panel remains readable. Keep the full input matrix and report exactly which entries were selected. Add a readable colorbar and genome-status legend. Do not claim that the selected panel reproduces the full published network.

## Acceptance criteria

- Every shown GII value comes from the supplied matrix.
- Ordering and selection are deterministic and documented.
- No biological analysis or significance test is introduced.
- All text uses the declared physical font size and stays inside the fixed canvas.
- PDF and PNG represent the same physical dimensions, without a tight crop.
