Within-depot myeloid subtype shares from the complete 16 × 3 Figure_2f source table in Massier et al., Nature Communications (2023), DOI 10.1038/s41467-023-36983-2 (source release https://data.mendeley.com/datasets/y3pxvr4xbf/2; CC BY 4.0). The color scale is one globally linear, nonnegative scale from 0 to 40%; its endpoints contain all 48 supplied percentages. Denominators are 11,470 subcutaneous, 8,563 omental, and 2,506 perivascular source objects. Subtype descriptors follow published Figure 2d annotations. These pooled object counts do not constitute independent biological replicates, and no test or expression claim is made. No values are clustered, normalized again, imputed, or filtered. SC, subcutaneous; OM, omental; PV, perivascular. In-cell labels display percentages rounded to two significant digits for comparing each subtype across depots; the color mapping and exported plotting table retain the full supplied precision. The deliberately compact matrix keeps row spacing and cell labels legible at the declared 110 × 88 mm canvas and 8 pt Arial size.
