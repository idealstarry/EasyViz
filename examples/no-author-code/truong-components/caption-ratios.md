Adapted from Truong et al., *Nature Methods* 21, 455–464 (2024), Fig. 1b ([article](https://www.nature.com/articles/s41592-023-02162-w), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)). Bars show the mean of the three **supplied** HDR/mutEJ ratios per condition, dots show those raw ratios, and intervals show sample SD (ddof = 1). Ratios are not reconstructed from group means. All 21 values remain visible. Hatched controls identify the no-donor/Cas9 and NTC conditions, for which the source caption declares ratios uninformative because very few fluorescence events were observed. The values of these controls should not be interpreted as precision estimates. This separate single-scale panel replaces the ratio layer on the original dual-axis figure; original comparison stars are omitted. No inferential tests were recomputed.
