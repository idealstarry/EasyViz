An alternative create view of the same selected Source Data. Each bar represents a component mean, dots are its three supplied biological replicate percentages, and intervals are component-specific sample SD (ddof = 1). HDR, both-signal and mutEJ are drawn side by side, so these intervals refer directly to each component rather than a cumulative stack. All 63 component observations, including 3 explicit zeros, remain visible. This is not an additional published panel.
