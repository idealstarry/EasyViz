EasyViz 0.5.2 strengthens Create design decisions and protects source data and reviewed versions during figure revisions.

### Track improvements

- **Create:** plan the main comparison before allocating panels, labels and guides. Distinguish primary evidence from lookup detail, and choose literature mechanisms for the reading task rather than adopting one palette or layout.
- **Statistics:** preserve adopted comparisons, adjusted P values and observation populations when styling Create candidates. Save profile and analysis paths so specifications can be replayed from another working directory.
- **Radial layouts:** add ordered category bands, balanced label placement and physical capacity diagnostics. The helpers arrange supplied geometry; they do not infer trees or change quantitative branch lengths.

### Workbench and MCP

Acceptance and downloads now target the displayed attempt and version. Restoring an accepted result retains its separate caption and distinguishes a historical snapshot from current output.

The normal loop remains **Save drafts → ask the original Agent chat to apply the comments → compare the fresh result**. Optional MCP submission requires that original Agent to be active and waiting; it does not start an idle chat.

### Reliability and validation

- Protect data, specifications, profiles and analysis inputs from export-path overwrites, including linked aliases.
- Focused recipes reject nonzero values that would silently underflow to zero. Preserve caller-relative settings when saving a specification.
- Keep local workbench display names in the user's project while excluding them from portable builds; retain compatibility with older archives.
- **893 runtime/workbench tests and 42 focused build/package checks passed.** Extracted-package redraws, vector/font/source checks and local installation were verified.
