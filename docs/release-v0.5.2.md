# EasyViz 0.5.2

Create now plans the main comparison before allocating annotation tracks,
labels and guides. The guidance applies lessons from actual drawing revisions:
balance the primary evidence and supporting layers, use complete tables for
lookup detail where appropriate, and judge literature mechanisms by the
reading task rather than copying one palette or layout. The two tracks remain
Create and Reproduce.

New standard-library radial layout helpers preserve ordered identities while
merging continuous category bands and balancing crowded labels inside explicit
capacity limits. Geometry reports keep tree, track, label and guide dimensions
separate; they do not infer a tree or change quantitative branch lengths.

Repairs protect source files from export aliases, preserve adopted analysis in
Create candidates, reject silent numerical underflow, bind workbench acceptance
and downloads to the reviewed version, and restore separate figure captions.

The normal workbench workflow remains **Save drafts → ask the original Agent
chat to apply the comments → compare and accept the fresh result**. MCP can
submit directly while that original Agent is active and waiting.

See [validation and limits](validation-v0.5.2.md). These changes strengthen the
workflow and tested geometry; they do not establish universal publication
aesthetics, model-wide gains or automatic idle-session continuation.
