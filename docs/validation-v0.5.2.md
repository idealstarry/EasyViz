# EasyViz 0.5.2 validation

This release strengthens Create's first finished output through evidence-first
organization and conditional geometry decisions. New radial helpers preserve
identities and report physical capacity; they do not infer scientific tree
geometry or choose an aesthetic winner.

The [release QA record](../evals/release-qa/v0.5.2/README.md) records the actual
test results, package checks, repaired defects and their limits. Independent
source review checked the new guidance and runtime changes; regressions cover
real rendering, analyzed populations, numerical representability, input/output
aliases, stale browser acceptance, separate caption restoration and scoped
downloads across two attempts.

The normal workbench workflow remains **Save drafts → ask the original Agent
chat to apply the comments → compare the fresh result**. MCP submission uses
the original Agent while it is active and waiting. This release does not
establish native idle-chat continuation or universal client compatibility.

Drawing refinements inform reusable decisions; they are not a held-out test of
first-draft quality. The layout smoke check is synthetic. Neither unit tests,
numerical optimization comparisons nor a known successful drawing establish
publication aesthetics for unfamiliar tasks or improvement across every model.
Both Create and Reproduce require scientific and actual-image review.
