# Evaluations

Keep quality evidence separate from the public showcase. A simple synthetic chart can test an export or statistical invariant without setting the design ambition for create.

| Material | Purpose |
| --- | --- |
| [fixtures/](fixtures/) | Rendered synthetic fixtures for five built-in chart families; generated by `scripts/run_demos.py` |
| [reproduce-inputs/](reproduce-inputs/) | Reference crops, requests, data dictionaries, source data and independently read specifications; author code was withheld |
| [Real-data cases](../examples/README.md) | Complete create and reproduce implementations with local QA |
| [Renderer tests](../tests/test_renderer.py) | Statistical results, experimental units, missing values, denominators, clipping, fonts, physical dimensions, and failure handling |
| [Generalization cases](generalization/) | Changed-size and adversarial synthetic inputs; preserved baseline, repaired behavior, and explicit boundaries |
| [Transfer input](transfer-inputs/paired-effects/) | Unseen supplied-effect/interval task outside the core renderer; a custom implementation tests the skill workflow separately |
| [Style comparison](style-review/) | Three palette alternatives, user selection, consistent mark outlines and actual-image review |
| [Legend literature](legend-literature/) | Four measured published panels, frozen create-case baselines and independent before/after inspection |
| [Legend transfer](legend-transfer/) | Ten identical-input comparisons across category counts, label lengths, canvas sizes and quantitative guides; actual export checks |
| [Acceptance record](../docs/acceptance.md) | What has been checked and what remains uncertain |

The initial blind input folder was named `examples/blind-inputs/` during the recorded runs. It was relocated here when the repository was organized; access logs retain their historical paths and record the relocation. Isolation in these runs was instruction-based. It is not an enforced filesystem or network denial.

Synthetic input data and specifications are portable runtime fixtures under `skills/easyviz/assets/fixtures/`. They are not biological observations.
