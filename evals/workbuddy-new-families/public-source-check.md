# Public-source check before WorkBuddy binding

The prepared input is a header-renamed derivative of the public Source Data accompanying Urschel et al., Nature Communications 15, 3077 (2024), DOI 10.1038/s41467-024-47429-8. The official article's Data availability section identifies Figure 1–6 raw data as available in the public repository https://zenodo.org/records/10815331 and links the Source Data workbook. Its Rights and permissions section states CC BY 4.0. Verified directly on 2026-10-02 via https://www.nature.com/articles/s41467-024-47429-8.

The CSV contains published coded participant identifiers such as NatCom_2024_001, already disclosed numerical observations and source sheet/row/cell references. It contains no real participant names, contacts or user-private medical data. Raw workbook URL and SHA-256 are documented in the repository source audit; only three column headers have changed in this trial.

The first UI binding attempt was rejected by automatic approval review because it treated the prepared input as sensitive participant medical data without specific WorkBuddy authorization. No task has been submitted, and no alternative UI/API route was attempted. The official public-source facts above were checked after that rejection as permitted evidence for a potential retry.
