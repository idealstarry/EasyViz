Empirical cumulative distribution functions of spike-specific IgG concentrations measured before and after vaccination. Data are from the publicly available Source Data of Urschel et al., *Nature Communications* (DOI: 10.1038/s41467-024-47429-8), published under a CC BY 4.0 license. Concentrations are reported in WHO-standardized binding antibody units per millilitre (BAU/ml). Each of the 127 study participants contributed a complete Before/After measurement pair; for this panel the measurements at each time point were pooled across prior-infection status (64 participants with prior infection and 63 without), so each curve summarizes 127 measurements. The observational unit is the individual measurement; the time-point labels pool observations and are not independent experimental units, and the pooling removes participant pairing from the visual encoding. Curves show the right-continuous empirical cumulative fraction F(x) = count(value ≤ x)/127, retaining every observed value as a step. In this dataset each time point contains 127 distinct measured values (no tied values), so no tied-value jump appears in either curve; the step construction would retain such jumps if present. Values are plotted without binning, smoothing, statistical testing, or interval inference, and the horizontal tails extending to the displayed axis limits are display extensions rather than added observations. This cumulative view is a descriptive supplement to the paired analyses in the source study and should not be read as a paired effect estimate.
