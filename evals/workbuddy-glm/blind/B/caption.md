Figure 1. Prepared ratio by readout and preparation batch. Horizontal points show the Prepared ratio; line segments span the given asymmetric 95% intervals (Lower 95, Upper 95) exactly as provided. Data are synthetic engineering data; the independent sample size n and the method used to construct the intervals were not supplied, so intervals were not refitted, weighted, or recalculated, and no statistical tests were performed. The horizontal axis is on a log scale with a dashed reference line at 1. Points are drawn hollow when the given interval contains 1 and solid when it does not; this reflects reference-overlap state only and does not imply statistical significance. Readouts are ordered by first appearance in the source table; all 11 provided rows are shown, and the three readout/batch combinations not present in the data (Background suppression / Batch B, Temperature sensitivity / Batch A, Storage response / Batch B) are left blank. Colors: Batch A (blue), Batch B (vermillion).
