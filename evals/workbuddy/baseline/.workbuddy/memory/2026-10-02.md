### 两个关键经验（可复用）

1. **matplotlib `scatter(s=...)` 是「标记直径的平方」，不是几何面积。**
   本机环境 matplotlib 3.11.1 下实测：`s` 与渲染直径满足 `d_pt = sqrt(s)`。
   因此要让「面积正比于数值」且直径标定为 D_max，应写
   `s = fraction * (D_max_mm * 72/25.4)**2`，而不是 `s = fraction * pi * r**2`。
   后者会把每个点缩小 √π ≈ 1.77 倍（半径缩到 1/√π），实测偏小 11%。
   **一定要用栅格化后的像素测量来复核，不要只信代码。**

2. **版心留白不要用「字号推算」的方式建模，要用渲染后的真实 ink bbox 迭代。**
   旋转 90° 的 y 轴标题（如 "Cell type"）实际 ink 高度比 8pt×1.2 的估算大，
   按公式算出来的左边距会让标题被画布边缘裁掉。
   可行做法：`fig.canvas.draw()` → `fig.get_tightbbox(renderer)`（单位英寸）
   → 计算与目标留白的差值 → 平移/缩放 axes → 重画，2 轮即收敛。
   注意 fig bbox 的 y 方向要换算成 mm 时用 `ink.y1/MM` 得到距底部距离。

### 其他可复用细节

- matplotlib 默认把 SVG 写成 pt（`width="340.15748pt"`），可用正则只改 width/height 为 `mm`
  （viewBox 不动），物理尺寸不变、更符合投稿要求。
- `svg.fonttype="none"` + `pdf.fonttype=42` → SVG 保留可编辑 `<text>`，PDF 嵌入 TrueType
  （`/FontFile2`，BaseFont 形如 `CAXPDD+ArialMT`），不转曲。
- macOS 上没有 `pdftoppm` 的 PATH，但 `/opt/homebrew/bin/pdftoppm` 可用，适合做
  「用独立渲染器复核 PDF」的检查。
- 零值用 `marker="x"`（常数尺寸、非数量符号）标出，面积严格为 0；验证方式是比较
  ink 在其自身 bbox 内的填充率（叉 ≈ 0.24，实心圆 ≈ 0.79），而不是数像素。
- 本机环境：`/Users/starry/Desktop/EasyViz/.venv/bin/python`（matplotlib 3.11.1 /
  numpy 2.5.3 / pandas 3.0.5），Arial 位于 `/System/Library/Fonts/Supplemental/Arial.ttf`。
