# EasyViz 0.5.0 release QA

Date: 2026-10-06. Baseline: released 0.4.6. Canonical runtime: `skills/`;
publication tag: `v0.5.0`. The release has two tracks, Create and Reproduce,
with a shared workbench and an optional MCP adapter.

## Implemented changes

- Create adopts a question, reading task and leading layer; retrieves 11
  conditional literature mechanisms and checks actual physical capacity.
  Alternatives within the same chart family remain available; custom code
  handles unsupported organizations.
- Statistical annotations can bind to an adopted result, raw/adjusted P and
  an explicit all/included observation population. Recoloring preserves the
  result rather than recomputing the test.
- Reproduce records structural matches, changed-data adaptations and unknown
  layers. The new scWAT broken-axis example has 60 real values, 12 mean/SEM
  summaries, an original/output comparison and independent image review.
- The workbench renders supported core cosmetics from code, shows request
  outcomes, compares attempts and accepts/restores verified versions. An
  optional project-scoped MCP adapter shares those operations with 13 tools.
- Runtime review repaired publication/recovery, cancellation and child-process
  cleanup defects. Packaging and installation now stage and validate changes
  before replacing owned files, with rollback for caught failures. File digest
  memory is bounded; timing is not claimed to improve.
- The MIT copyright is `Copyright (c) 2026 idealstarry`.

## Limits

Create inputs were frozen after development began and before the fresh Agent
runs. Seven tasks adapt known studies; one is synthetic and deliberately
ambiguous. There is no matched with/without-skill effectiveness result, novice
trial or CNS-level quality guarantee. Independent notes include a large compact
bar label band, some crowded raw marks and optional row-spacing improvements.
The darker cohort palette only partly matches the project's brighter preference;
the guidance now preserves that preference without weakening small-mark clarity.

MCP passed official protocol and extracted-runtime checks. Saving requests does
not activate an idle Agent; custom and free-form modifications require an active
Agent. Protocol checks do not establish automatic cross-client Agent execution.

Four new unfamiliar references, optional panel assembly and source-data packs
remain research targets. A Reproduce adoption checkpoint is not visual approval.
Transactional publication uses individual file renames and caught-failure
rollback; it does not guarantee recovery after forced process termination.
Cross-platform fonts and large dense SVG interaction remain separate checks.
