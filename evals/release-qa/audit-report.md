# EasyViz release audit

Status: the three demonstrated scientific input defects found in this pass are fixed in canonical sources. No remaining release blocker identified within this audit scope. Root must synchronize bundled cases and rebuild the plugin before release.

## Findings and corrections

1. **P1, fixed: scatter ignored `statistics.unit`.** Original location: `skills/easyviz/scripts/render.py:242-243`; corrected resolution/checks now at lines 236-250. Fresh CSV with six rows from three repeated subject IDs, `statistics={"method":"pearson","unit":"subject"}`, returned `status=pass`, `n=6`, `p=0.003609355463567543`. Moving the same ID mapping into `fields.unit` rejected it. The fix resolves both declarations consistently, rejects conflicting declarations, and validates present/nonempty IDs before testing. Pearson and Spearman regressions cover both aliases; unique IDs retain the expected results. Baseline evidence: `probe-results.json`, `repeated.csv`, `stats_unit.json`.

2. **P2, fixed: blank participant IDs were paired.** Original location: `examples/create/paired-myeloid-remodeling/plot.py:35-43`; corrected validation at lines 32-34. Fresh baseline/follow-up records with participant `""` were accepted as one participant with change 1. CLI CSV parsing preserves empty strings, so the later `isna` guard did not catch them. Blank/whitespace/missing cohort, participant, and subtype identifiers now reject before pairing. Literal `NA`, `null`, and leading-zero participant IDs remain valid. Baseline evidence: `case-probe-results.json`, `blank-subject.csv`.

3. **P2, fixed: annotated matrix recipe reinterpreted literal `NA` ID as missing.** Original canonical location: `examples/create/annotated-inhibition/plot.py:37-43`; corrected parsing/validation at lines 38-52. A valid fresh 2 x 2 square matrix with row/column identifiers `NA` and `B` failed its row/column identity assertion. Matrix and metadata parsing now preserve literal identifiers; raw column headers plus row/annotation IDs explicitly reject empty values. A new 3 x 3 synthetic render preserves `NA`, `null`, and `001`, all nine supplied values, and source-to-output orientation. Baseline evidence: `case-probe-results.json`, `literal-matrix.csv`, `literal-genome.csv`.

4. **P3, handled by root: packaged BMI adopted specification had an invalid any-directory invocation and developer interpreter path.** `skills/easyviz/assets/cases/massier-bmi-violin/adopted-spec.md:38` and its source originally advised `python plot.py` from any working directory. The same text existed in the ZIP. README already used the correct absolute case-script form. The narrow package audit found no other broken Markdown-linked resources or executable development-tree paths in that ZIP.

Also changed the paired case's Matplotlib cache default from a macOS-specific `/private/tmp` location to `tempfile.gettempdir()`, per root's instruction.
