EasyViz 0.4.3 makes basic Create panels the starting point: refine colors, mark
boundaries, line hierarchy and proportions before adding composite layers.
Create and Reproduce remain separate tracks.

- Shared crisp starting values for new drafts and distribution previews, with explicit legacy replay and preserved saved specifications.
- Optional outlined replicate bars and violin quartile/median summaries, with source-to-artist checks and unchanged scientific quantities.
- Five runnable basic panels from attributed Source Data: bars, scatter, box, violin and a simple heatmap. Each includes data, settings, separate captions, editable exports and a bounded transfer probe.
- Advisory measurements of actual mark sizes, contrast, strokes and legend bounds; these support visual review without altering marks.
- README now leads with basic Create examples.

Validation: 413 unit tests passed, extracted-package runs and reviewed PNG/data
replay passed, and five saved core specifications retain identical pixels.
Independent review preferred four revised basic panels; the scatter comparison
was a tie. The violin comparison includes an added summary layer. These
results are scoped to the tested inputs.
