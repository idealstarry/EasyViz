Each colored connector joins the literal person_id pair; the shared deterministic categorical offset within a pair changes only display position. The logarithmic measurement axis is explicitly labeled in BAU/ml; no pseudocount or numeric value transformation is applied to saved measurements. Black supporting segments show the median and IQR, calculated on the original measurement scale with linear quartiles.
