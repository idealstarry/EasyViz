# Create literature refresh

The user rejected the earlier muted/faded Create style for the paired-myeloid
and inhibition examples. That outcome is retained in the historical
[style-refinement review](../create-style-refinement/independent-review.md);
its original candidate images now have immutable snapshot paths.

This iteration starts from actual PDF figures in the three user-supplied
papers, recorded in [independent reference reading](reference-reading.md) and
[source hashes](source-records.json). PROGENy, scWAT and Vanneste provide
specific mechanisms: definite contours, opaque observations, bright category
identity, role-specific strokes and repeated aligned geometry. These are
conditions to consider, not a uniform journal preset.

## Final cases

- Paired myeloid: aligned cohort facets, opaque packed participant points,
  separate outlined IQR strips and local below-zero ledgers. The scWAT PDF
  vector pair is explicitly reassigned to Petrus/Kerr. The hollow-point trial
  failed dense-row capacity; its evidence is retained. Tiny final dots remain
  a display-size compromise. See [independent review](paired-independent-review.md).
- Inhibition: blue/white/gold/orange/coral stops, definite mean bars and binary
  metadata. Two signed linear branches explicitly put zero at the center.
  Values and original-minute guide labels remain intact; this is a declared
  normalization change from the old globally linear range. See
  [case review](../../examples/create/annotated-inhibition/independent-review.json).

[Manifest](manifest.json) pins matched before/after identities and dimensions.
[Numerical verification](numeric-verification.json) separately recomputes all
832 paired differences, 32 paired summaries, 400 displayed matrix values and
152 full-matrix means; 12 input/derived tables are byte-identical to `ede4609`.
The main and five-year paired recipes replay from the extracted package.

## Reusable behavior and forward use

Core fixed-size observation styling now exposes filled/hollow symbols and
matching legends, outline boxes, physical stroke-aware point packing, and
explicit box thickness. Quantitative filled-area circles retain their contract.
Accepted specifications and profile fallbacks are preserved. Directory previews
accept the same explicit treatments and audit actual artists.

A [forward-use request](forward-test/output/first-use-interpretation-review-log.md)
used 54 independent **synthetic** measurements. An independent agent selected
box/points over ECDF for individual lookup and summaries. Its review identified
oversized boxes and generous group spacing. A guided hollow/outline extension
showed **no clear preference**: less fill exposed whisker crossings. This
supports keeping hollow treatment conditional, rather than claiming improvement.
The parent then tested a narrower outline box with opaque filled points in a
third, self-reviewed [compact attempt](forward-test/output/guided-compact/).
All original first-use artifacts and judgments remain intact.

These checks cover these data, fonts, sizes and recipes. They do not establish
use-versus-no-use gain, domestic-model effectiveness, novice effectiveness,
arbitrary-data generalization, or publication acceptance. Final user acceptance
of the refreshed two showcase images remains pending.
