# Two-track workflow trials — 0.4.0

These are bounded local Agent usability trials on synthetic inputs, not model comparisons or biological findings. Fresh implementers read the current Skill and necessary resources under instruction-based access restrictions. Their directories were not isolated by an operating-system sandbox.

## Create

A directory of 24 independent specimens, two measured fields and a data dictionary was supplied without a chosen chart. The Agent inventoried the data, proposed three reading tasks, adopted descriptive analysis and rendered a boxplot with every point. Actual image review corrected one point overlap by changing the jitter seed; both attempts remain. [Behavioral report](create/behavioral-test-report.md) distinguishes the executed helper snapshot from subsequent development edits.

[Accepted panel](create/primary-signal.png), [caption](create/caption.md), [numeric/export checks](create/verification.json) and [replay checks](create/replay-verification.json) retain the test scope. The irrelevant paired recommendation and paired-only prose discovered in this trial were corrected afterwards; tests now require confirmed independent design to exclude paired candidates. Raw-point overlap still requires actual image review.

## Reproduce

The separate trial supplies only a reference crop, fourteen synthetic user summaries, their meanings and a saved independent reading of the same image. It excludes paper Source Data, author plotting code, case implementations and development evaluations. The implementer uses the saved reading truthfully, inspects the image itself, adopts reference layers and writes new plotting code. Its final [report](reproduce/trial-report.md) and evidence retain the exact access and review scope; the final visual review is the implementer's own, not a newly independent review.

## Shared workbench

The parent used the Codex in-app browser to select a categorical legend and point group, save two instructions, drag a canvas region and undo that region note. It then read the saved ledger, edited the configuration and rendered a new attempt. [Round-trip evidence](workbench/roundtrip.json) verifies an exact 2 mm horizontal legend-anchor shift, the requested category color, identical plotting data, unchanged old exports and unchanged 120 × 90 mm canvas. SVG, PDF and PNG were rerendered together.

HTTP regressions additionally cover stale versions/maps, cross-origin writes, SVG sanitization and malformed inputs; executed JavaScript regressions cover pending/failed reloads and mutation-response races. The local page collects instructions for an Agent; it does not execute arbitrary scripts or edit quantitative observations by dragging.

Temporary absolute paths and recorded hashes identify these historical runs. Copying a fixture for another run requires new paths, a new attempt and new review. The runtime caches and duplicate replay exports are omitted from this evidence folder.
