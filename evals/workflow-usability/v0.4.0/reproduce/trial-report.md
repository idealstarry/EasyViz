## Practical instruction/tool observations

1. The packet accepts and hash/schema-validates the supplied structured reading and truthfully saves `reader.image_viewed=true`, yet its stdout still says `image_reading_performed=false` and asks for a fresh reading. This refers to the staging tool doing no semantic reading, but the field/next-action wording is easy to confuse with absent supplied evidence. The root agent subsequently reports fixing the CLI presentation to `image_reading_performed_by_tool=false` plus `supplied_reading_schema_validated`, with a conditional next action acknowledging accepted supplied readings, and adding a regression test. This trial invocation predates that correction; the figure output requires no rerender, and this child did not inspect the new test.
2. The currently available `timecourse` recipe is discoverable through `render.py --describe-spec` and its reference documents this exact dual-axis mean/SD-band contract. It is absent from the main SKILL.md shared-resource table. The custom route was valid and completed from zero; the recipe was discovered and read afterwards. Add its focused documentation link to the main resource index to reduce unnecessary custom implementation.
3. `--custom-script` declares a planned path but creates no script or parent implementation directory, consistent with the documentation. The caller must make the directory before writing; an initial write hit a missing-directory error and was corrected. A printed `mkdir`/next-step hint would make the handoff more concrete without implying runnable code was generated.
4. Mixed user notes have scientific definitions and styling directions, but packet evidence types accept only caption/methods excerpts. This run staged the explicit notes as `methods-1`, and retained the original filename/path. A dedicated notes/request artifact type would distinguish study methods from user adaptation decisions.
5. Generic `setup`/`export` correctly preserve dimensions, typography and semantic mapping, but custom code still owns scientific-layer audits and full provenance. This run explicitly implemented those audits and recorded reference/notes hashes because export’s figure metadata alone records only a single data/spec/script path. This is a documented boundary, not a missing capability.

One bounded trial establishes the checked supplied-summary contract and adopted structure. It does not establish arbitrary-reference transfer, exact pixel replication, independent aesthetic approval or publication acceptance.
