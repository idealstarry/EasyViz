# Independent viscosity preview trial

This is a newly authored synthetic fixture for a forward usability trial, not measurements from a real experiment or a previous EasyViz example. Each row is one independently prepared sample in the declared trial scenario, measured once at 25 C; the observational/experimental unit is the literal observation_id. Formulations A, B and C contain 17, 19 and 21 observations, respectively. No ID recurs and there are no technical replicates, repeated measurements or paired units.

The same median (8.4 mPa·s) was deliberately used with a compact distribution, a broad two-sided distribution and a long upper tail, so median comparison and tail inspection ask different reading tasks. Some exact ties and close measurements stress physical beeswarm placement. Literal IDs 001, NA, null, N/A, NaN and 0007 are valid source identities. Unused temperature_C and batch_note columns must remain traceable. No inferential test, confidence interval or effect estimate is requested.

Adopted display: 110 × 80 mm, Arial 8 pt, opaque category colors #0072B2 / #D55E00 / #009E73, common linear measurement axis with limits 4–17 mPa·s, no in-image title, PNG/PDF/SVG exports. Default two choices are requested first; a second explicit request opts into a violin when eligible. Five distinct values is an eligibility guard, not evidence that KDE shape is reliable.
