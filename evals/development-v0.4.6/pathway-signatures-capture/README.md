## Implemented capture

`plot.py` resolves the source-handoff helper through normal import discovery:
a deliberately staged `PYTHONPATH` takes precedence over the ordinary appended
runtime directory. It compiles the exact captured handoff/workbench source
snapshots, verifies the currently executing case code against its source, and
verifies the captured renderer and its six sibling helper snapshots against
the renderer's own executing-source records before drawing. The complete
capture declares three primary sources, the source contract, and nine actual
executing helper sources. CSV, specification and contract are parsed directly
from the returned capture bytes. The figure's source-bound artist map uses
those consumed digests; settings and QA expose matching source bindings.

`handoff.json` records the pre-export consumption evidence, actual exported
files, adopted specification and auxiliary identities. `consumed-sources.json`
records the current receipt identity and executing helper claims. This is
explicit declared consumption evidence: it does not discover every third-party
dependency or certify arbitrary caller behavior, scientific meaning or
aesthetics.

The case validator independently checks these current primary/auxiliary paths,
byte identities, executing-helper declarations, artist/export records and
canonical UTF-8 specification identity. Nine verified-current temporary copies
reject six earlier numerical/artist corruptions and three additional contract,
helper-declaration and receipt-identity corruptions.
