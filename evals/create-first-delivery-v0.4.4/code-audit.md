# Create helper correctness audit

Read-only code review of `create_candidates.py` and `create_review.py`, followed by targeted checks against the real exporter. This audit checks preservation and review bindings; it does not establish visual quality or statistical validity.

| Finding in the initial implementation | Proof / meaningful branch | Resolution and verification |
| --- | --- | --- |
| Profile bytes were reread after measured planning, although the resolved specification and provenance hash came from the earlier read. | A live profile change between planning and snapshotting could put different bytes into `profile.json`. The original profile test exercised a stable file only. | The helper now captures and checks the adopted bytes immediately after resolution, then writes those exact bytes. The new drift test changes the live canvas/colors after the first draw: frozen exports retain the original choices and the overall result is `needs_revision` because the live input changed. Independently passed. |
| The renderer exception branch could replace a measured `needs_revision` with the saved `qa.status=pass`. | The normal-return numeric-artist test did not cover a failure after QA publication. A targeted check combined incorrect quantitative artist coordinates with an exporter that wrote its real passing QA and then raised `OSError`. | Exceptions now produce `failed` while retaining the recorded renderer status. The combined check returned geometry `needs_revision`, candidate `failed`, manifest `needs_revision`; the dedicated late-exception regression also independently passed. |
| PDF/TIFF dimensions used saved QA metadata without binding those measurements to the current export bytes. | Before staging, replacing a real exported PDF with a tiny invalid file still produced `export_dimensions=passed`, `technical_qa=passed`, and a complete fixture attestation could obtain `gate_status=recorded`. Post-stage stale checks did not cover this branch. | Shared export measurements now include per-format SHA-256. PDF/TIFF saved measurements require matching hashes: mismatches fail and absent hashes remain `not_checked`. Replaying the original 28-byte invalid PDF now gives dimensions `failed` and gate `blocked`, even while the unchanged saved technical QA says `passed`. An alternate real TIFF with identical dimensions/DPI is also rejected. Independently verified. |

The existing coverage also checks explicit numeric limits/scales/point sizes, category order, fixed cosmetics and manual geometry, violin KDE/inner-summary semantics, heatmap values/normalization, descriptive replicate methods, fresh outputs, dense packing failures, and honest `--no-render` results. Review tests bind exports/source/spec/profile/caption/QA, reject stale records and unresolved major findings, and prevent an attestation from upgrading measured `failed` or `not_checked` evidence.

Independent targeted run after the candidate fixes: 3 tests passed (profile drift, late renderer exception, and actual neutral summary artists for more than four labeled groups). A temporary misplaced palette variable was corrected before this run; it is not an outstanding finding. No engine or gate files were edited by this audit.

Independent targeted run after the export-binding fix: 7 tests passed (pre-stage invalid PDF, replacement TIFF with matching dimensions, missing PDF/TIFF hashes, directly measured PNG/SVG without optional hashes, stale rerender, missing custom metadata, and measured failure that a review cannot upgrade). The original invalid-PDF proof was also replayed directly with the real exporter. All three findings above are resolved in the reviewed working tree.

PNG/SVG physical metadata is measured directly; PDF/TIFF uses hash-bound saved exporter measurements rather than claiming a fresh parser measurement. Typography acknowledges the saved actual-font/point-size records and does not infer embedding from a raster preview. `recorded` confirms current artifact bindings and a complete attestation; it cannot prove an image was opened or certify aesthetics/scientific correctness.
