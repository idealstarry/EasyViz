# Installation and package fix review

Independent read-only review of `scripts/install_plugin.py`, `scripts/check_package.py`, and the completed `scripts/build_plugin.py` changes. Runtime probes use temporary fixtures; no real desktop installation, owner-code edit, release build, or network operation was performed.

| Additional finding | Reproduction | Fix review |
| --- | --- | --- |
| A catalog edit after the initial re-merge could be lost at commit. | Appending another plugin immediately before the selected catalog write gave `status=installed` but removed that new entry. | A shared catalog lock and a client/cache lock serialize cooperating EasyViz installers. The final catalog write checks the expected bytes; the original injected edit now aborts before CLI mutation and preserves the exact external bytes. Independently passed. |
| macOS case-insensitive ZIP aliases could overwrite each other. | ZIP entries `easyviz/README.md` and `easyviz/readme.md` extracted as one inode containing the second entry, although extraction returned two entries. | ZIP duplicate and parent-conflict keys now use NFC normalization and case folding. Exact case and composed/decomposed Unicode regressions independently passed. |
| A caller-selected output ancestor alias could redirect a build into its authoritative source tree. | An external alias pointing to `repository/skills`, followed by `build(alias/generated-build)`, called synchronization, created the output inside `skills`, and reached recursive source copying. A spy stopped before the actual recursive copy. | Build overlap checks now also compare resolved physical paths. This retains ordinary system aliases while rejecting physical overlap before synchronization, with all source bytes unchanged. Independently passed. |
| The two installer locks could refer to the same physical file. | With `CODEX_HOME=home/.agents`, catalog and client locks coincide; a single installer reported another installation running before calling the CLI. | Locks are deduplicated by resolved physical path. This custom client-home fixture now completes a verified installation. Independently passed. |

The primary fixes were reviewed for complete source-tree rejection of file/directory symlinks and special resources, backup of the predetermined same-version cache before CLI mutation, exact source/cache rollback, preservation of unrelated catalog entries and metadata, avoidance of an untrusted returned path during rollback, strict installed/enabled booleans, ZIP entry/member/total budgets, duplicate and file/directory preflight, and existing extraction symlink preservation.

The catalog locking guarantee concerns cooperating EasyViz installers. An arbitrary external editor does not acquire these locks; the expected-byte check detects changes observed before the atomic replace. This is not a general filesystem compare-and-swap guarantee for every external writer.

After the owners froze these files, an independent run of `test_install_plugin`, `test_package_extraction`, and `test_build_plugin` passed **50 tests** in 2.927 seconds: 26 installer, 8 extraction, and 16 builder tests. The suite includes all four reproduced branches above, rollback after same-version/new-version CLI mutation and partial backup failure, real process-lock contention/release, source and extraction symlink/special-file preservation, case/Unicode aliases, conflicts, budgets, and repeatable default/external builds. A transient in-progress test edit was corrected before this final validation; it is not a release finding. `git diff --check` passed.

All four additional findings are resolved in the reviewed working tree. The tests ran on the current macOS host; they do not establish execution coverage of the Windows-specific lock branch.
